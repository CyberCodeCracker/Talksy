## Talksy

Talksy is a modern and lightweight messaging application designed for seamless communication. Inspired by the simplicity of WhatsApp, it focuses on fast, secure, and user-friendly chatting. With a casual and friendly vibe, Talksy helps users stay connected with friends, family, and groups effortlessly.

## 🚀 Features

* Real-time messaging using WebSocket.
* One-to-one private chats.
* Group chat support with multiple members.
* Secure authentication using access & refresh tokens.
* Smooth and responsive UI built with Angular.
* Scalable Spring Boot backend with REST APIs.

## 🛠️ Tech Stack

* Spring Boot (REST API, security, token system)
* WebSocket for real-time messaging
* JWT (access & refresh tokens)
* Angular for the frontend
* Bootstrap & SCSS for styling
* PostgreSQL
